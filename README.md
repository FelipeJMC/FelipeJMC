### 🧭 What I do

I work on enterprise .NET systems: migrating .NET Framework applications to modern .NET, integrating them with Oracle-backed ERPs, and shipping them to AWS through containerized CI/CD pipelines. Most of my day-to-day lives at the intersection of **legacy modernization, application security, and cloud infrastructure**.

- 🔭 **Currently working on:** .NET Framework → .NET 8/10 migrations, Blazor front-ends, and Oracle/EF Core integrations running on AWS ECS Fargate.
- 🔐 **Focused on:** authentication with Microsoft Entra ID, hardening back-end services, and closing CVEs in container images.
- 🌱 **Currently learning:** AWS Certified Developer – Associate (DVA-C02), cloud-native patterns, and performance tuning for large-scale systems.
- 💬 **Ask me about:** .NET migrations, PL/SQL and Oracle troubleshooting, GitLab CI/CD with Docker, or modernizing applications nobody wants to touch.
- ⚡ **Fun fact:** I've been playing World of Warcraft since 2008 and I'm still not good at it. 😂
